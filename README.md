# Hotel Booking Analysis

## Project Overview

This is my first data analytics project, built as a learning exercise to practise working with a hotel booking dataset using Microsoft Excel.

The goal was to explore hotel booking data, clean and transform it, and uncover basic patterns around cancellations, guest types, and room preferences using Pivot Tables and an Excel Dashboard.

---

## Dataset

- **Source:** Kaggle
- **Topic:** Hotel bookings (City Hotel & Resort Hotel)

---

## Tools Used

| Tool | Purpose |
|------|---------|
| Microsoft Excel | Primary analysis tool |
| Power Query | Data cleaning & transformation |
| Pivot Tables | Summarising and analysing data |
| Excel Dashboard | Visualising key insights |

---

## What I Did

1. Loaded the dataset into Excel using **Power Query**.
2. Removed unnecessary columns to keep the data clean and focused.
3. Performed required **data cleaning and transformation**.
4. Created a **Room Type** classification column using Excel logic (`IF`/`AND`) to classify bookings as *Desired* or *Un-Desired*.
5. Created a **Guest Type** classification column using `IF`/`AND` to classify guests as *Couples*, *Family*, or *Singles*.
6. Built **Pivot Tables** to analyse booking and cancellation patterns.
7. Designed an **Excel Dashboard** to present the findings visually.

---

## Key Insights

1. **Overall cancellation rate:** 37.04%
2. **City Hotel** had a cancellation rate of **41.73%**, compared with **27.76%** for **Resort Hotel**.
3. **August** recorded the highest number of cancelled bookings: **5,239**.
4. **Couples** had the highest cancellation rate: **39.75%**.
5. **Desired Room** bookings had a **41.56%** cancellation rate, compared with just **5.38%** for **Un-Desired Room** bookings.

---

## Dashboard

The project includes an Excel dashboard covering booking volume, cancellations, hotel type, guest type, room preference, and monthly trends.
